# Explorador de iniciativas (React)

Laboratorio de la semana 11 de JavaScript Avanzado. Datos ficticios con fines educativos.

1. `npm install` (o `npm ci` si hay package-lock.json).
2. `npm run dev` y abre la URL que indique Vite.
3. `npm run verify` para build y 18 pruebas.

No incluir node_modules ni dist en la entrega.
