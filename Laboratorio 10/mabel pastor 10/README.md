# Portal académico Angular (PC2)

Laboratorio de la semana 10 de JavaScript Avanzado. Datos ficticios.

1. `npm install` (o `npm ci` si hay package-lock.json).
2. Terminal A: `npm run api` (http://127.0.0.1:3000/estudiantes).
3. Terminal B: `npm start` (http://localhost:4200).
4. `npm run verify` para build y 30 pruebas (no requiere la API).
5. `npm run api:reset` restaura la semilla (con la API detenida).

No incluir node_modules ni dist en la entrega.
